HƯỚNG DẪN CÀI ĐẶT NHANH - CAPCUT BACKGROUND EXPORTER

YÊU CẦU BẮT BUỘC TRƯỚC KHI CÀI:
Máy tính của bạn cần phải cài đặt phần mềm Node.js (Môi trường để chạy công cụ).

Link tải Node.js (Hãy tải bản LTS): https://nodejs.org/

CÁC BƯỚC CÀI ĐẶT

Bước 1: Giải nén toàn bộ thư mục công cụ này ra máy tính của bạn (VD: Desktop hoặc ổ D).
*Lưu ý: Không đặt công cụ trong thư mục có tên tiếng Việt có dấu.

Bước 2: Nhấp đúp chuột vào file [ install.bat ] để bắt đầu cài đặt.

Bước 3: Chờ đợi màn hình đen (CMD) tự động thiết lập hệ thống.
Quá trình này diễn ra rất nhanh. Hệ thống sẽ tự động thêm công cụ vào danh sách khởi động cùng Windows.

Bước 4: Khi màn hình báo "HOÀN TẤT", bạn bấm phím bất kỳ để đóng cửa sổ.

Bước 5: ĐỂ SỬ DỤNG NGAY LẬP TỨC (mà không cần khởi động lại máy tính), bạn hãy nhấp đúp chuột vào file [ run_hidden.vbs ].

-> XONG! Từ giờ mỗi khi bật máy tính, tool sẽ tự động chạy ngầm ở góc phải màn hình (khay hệ thống) có biểu tượng màu xanh lá.

GỠ CÀI ĐẶT (UNINSTALL)

Nếu bạn không muốn công cụ tự động chạy cùng Windows nữa, chỉ cần nhấp đúp vào file [ uninstall.bat ].

Sau đó bạn có thể xóa toàn bộ thư mục này đi một cách an toàn.
