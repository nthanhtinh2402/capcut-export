🇬🇧 Quick Installation Guide - CapCut Background Exporter

⚠️ Mandatory Prerequisites

Your computer must have Node.js installed (The runtime environment for this tool).

🔗 Download Node.js (Please download the LTS version): https://nodejs.org/

⚙️ Installation Steps

Step 1: Extract this entire tool folder to your computer (e.g., Desktop or D:\ drive).

Note: Do not place the tool in a directory path that contains special characters or Vietnamese diacritics (accents).

Step 2: Double-click the install.bat file to start the installation.

Step 3: Wait for the command prompt (CMD) to automatically set up the system.
This process is very fast. The system will automatically add the tool to your Windows startup list.

Step 4: When the screen displays "HOÀN TẤT" (Completed), press any key to close the window.

Step 5: TO USE IT IMMEDIATELY (without having to restart your computer), double-click the run_hidden.vbs file.

🎉 ALL SET! From now on, whenever you turn on your PC, the tool will automatically run in the background. You can find its green icon in the system tray (bottom right corner of your screen).

🗑️ Uninstallation

If you no longer want the tool to run automatically with Windows, simply double-click the uninstall.bat file.

After that, you can safely delete this entire folder from your computer.

💡 TIP: Press the F2 key to hide/show the software's UI dashboard at any time!

🇻🇳 Hướng Dẫn Cài Đặt Nhanh - CapCut Background Exporter

⚠️ Yêu Cầu Bắt Buộc Trước Khi Cài

Máy tính của bạn cần phải cài đặt phần mềm Node.js (Môi trường để chạy công cụ).

🔗 Link tải Node.js (Hãy tải bản LTS): https://nodejs.org/

⚙️ Các Bước Cài Đặt

Bước 1: Giải nén toàn bộ thư mục công cụ này ra máy tính của bạn (VD: Desktop hoặc ổ D:\).

Lưu ý: Không đặt công cụ trong thư mục có tên tiếng Việt có dấu hoặc ký tự đặc biệt.

Bước 2: Nhấp đúp chuột vào file install.bat để bắt đầu cài đặt.

Bước 3: Chờ đợi màn hình đen (CMD) tự động thiết lập hệ thống.
Quá trình này diễn ra rất nhanh. Hệ thống sẽ tự động thêm công cụ vào danh sách khởi động cùng Windows.

Bước 4: Khi màn hình báo "HOÀN TẤT", bạn bấm phím bất kỳ để đóng cửa sổ.

Bước 5: ĐỂ SỬ DỤNG NGAY LẬP TỨC (mà không cần khởi động lại máy tính), bạn hãy nhấp đúp chuột vào file run_hidden.vbs.

🎉 XONG! Từ giờ mỗi khi bật máy tính, tool sẽ tự động chạy ngầm ở góc phải màn hình (khay hệ thống) có biểu tượng màu xanh lá.

🗑️ Gỡ Cài Đặt (Uninstall)

Nếu bạn không muốn công cụ tự động chạy cùng Windows nữa, chỉ cần nhấp đúp vào file uninstall.bat.

Sau đó, bạn có thể xóa toàn bộ thư mục này đi một cách an toàn.

💡 MẸO: Bấm phím F2 để ẩn/hiện giao diện phần mềm bất cứ lúc nào!
